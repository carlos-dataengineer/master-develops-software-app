# Código de conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, acolha pontos de vista diferentes, aceite críticas construtivas e foque no que é melhor para a comunidade. Assédio, ataques pessoais e linguagem discriminatória não são tolerados.

Para relatar um comportamento inadequado, abra uma *issue* marcada como `conduta` ou use o contato privado indicado no perfil do mantenedor no GitHub. Todos os relatos serão analisados com confidencialidade.
