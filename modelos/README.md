# Modelos de referência

O Master Develops foi concebido a partir do estudo de padrões arquiteturais e operacionais de três projetos públicos e do Master Data Engineer, do mesmo autor. O mapeamento completo, item por item, está em [`docs/mapeamento-dos-modelos.md`](../docs/mapeamento-dos-modelos.md).

| Referência | Uso no Master Develops | Fonte oficial |
|---|---|---|
| Pstack | Skill de entrada, playbooks, princípios de engenharia, delegação | https://github.com/cursor/plugins/tree/main/pstack |
| Thermos | Revisão dupla em paralelo: corretude e manutenibilidade | https://github.com/cursor/plugins/tree/main/thermos |
| Ponytail | Menor mudança completa, sem cortar segurança nem acessibilidade | https://github.com/DietrichGebert/ponytail |
| Master Data Engineer | Painel em tempo real, instalador, memória contextual | https://github.com/carlos-dataengineer/master-data-engineer |

A adaptação é específica para desenvolvimento de software e aplicativos. Não é uma cópia, não é endossada pelos mantenedores dos modelos e não substitui os repositórios originais. Nenhum arquivo dos modelos é redistribuído aqui; as cópias de trabalho ficam na pasta local de construção do projeto. Cada projeto mantém sua própria licença e atribuição (veja `THIRD_PARTY_NOTICES.md`).
